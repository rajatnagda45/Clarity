# Current Features

Here is a comprehensive list of what is currently implemented in the frontend:

1. **Clerk Authentication**: Full sign-in, sign-up, and session management.
2. **Landing Page**: Highly animated marketing site with dynamic backgrounds and value propositions.
3. **Workspace Management**: Users can switch between workspaces (e.g., Personal vs Enterprise). The active workspace dictates all data shown in the app.
4. **Document Ingestion Hub**: Upload area for PDFs and DOCX files. Displays a list of uploaded documents with their current processing status (Indexed, Processing, Failed).
5. **AI Chat Interface**: A conversational interface to query the ingested documents.
6. **Command Center**: A globally available (Cmd+K) search and command palette.
7. **Developer Console**: A specialized dashboard showing the deep internals of the RAG pipeline, including token counts, vector storage sizes, and animated pipeline flow visualizers.
8. **Settings & Billing UI**: Tabbed interfaces for managing members, roles, API keys, and viewing plan quotas.
